# Parent guide video and screenshots

`mykidzlearning-parent-guide.mp4` (about 4 minutes, 1080p, English narration with on-screen captions) walks a parent through three parts:

1. **Create your account**: open the site, request an account, sign in with the temporary password, set your own password.
2. **Set up your child and rewards**: add the child (name, email, 4-digit PIN, class and group), set the rewards, then the overview, notebook checks, test answers, video links and child settings.
3. **How your child uses the portal**: sign in with email and PIN, home page, subjects and chapters (Sets 1 to 3), the three steps in a chapter, the test, the reward road, and the phone view.

- `screenshots/`: the plain screenshots (1280 x 900, phone view 390 x 844 at 2x), numbered in the order of the video.
- `slides/`: the same screenshots as captioned slides (1920 x 1080), as used in the video.

The child "Aarav" and parent "Demo Parent" are sample accounts made only for these screenshots and have since been deleted. The sample progress (120 points, one notebook waiting) was added to show how the screens look.

To re-make the video after the site changes, the capture scripts need to be re-run against a temporary demo parent and child. The narration voice is the macOS "Rishi" voice and can be swapped for a recorded voice-over.
